支持与帮助

PDF小匠的全部处理都在浏览器本地完成。遇到问题时，请先确认浏览器已更新到最新稳定版。

常见问题

  • 加密 PDF：1.0 版不支持设有打开密码的 PDF。
  • 压缩未达目标：文件可能已经高度压缩。可以选择更大的目标，或使用拆分功能分成多个文件。
  • DOCX 排版变化：复杂表格、文本框、浮动图片和特殊字体可能与 Word 不同，请在打印前检查预览。
  • 大文件处理失败：关闭其他占用内存的标签页后重试；浏览器本地处理受设备内存限制。

报告问题

请在项目 GitHub 仓库创建 Issue，并提供浏览器版本、PDF小匠版本、操作步骤和错误信息。不要上传包含个人或机密信息的真实文件；请使用可公开的最小复现文件。

安全问题

安全漏洞请使用 GitHub Security Advisories 私下报告，不要发布公开 Issue。

English support: Open an issue in the project's GitHub repository with the browser version, extension version, reproduction steps, and error text. Never attach a sensitive real-world document.
