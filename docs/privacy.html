隐私政策

生效日期：2026-09-17

简明结论：你的文件不会离开你的设备。PDF小匠不收集数据，不申请网站访问权限，也没有服务器、账户、广告或统计 SDK。

我们处理什么

用户主动选择的 PDF、JPG、PNG 和 DOCX 文件只在 Microsoft Edge 或 Google Chrome 的扩展页面内存中处理，用于生成用户要求的输出文件。

我们不做什么

  • 不收集、上传、出售、共享或分析文件、文件名及文件内容。
  • 不收集身份、浏览历史、位置、设备标识或使用数据。
  • 不创建账户，不使用 Cookie，不展示广告。
  • 不把文件写入开发者控制的服务器，不加载远程执行代码。

保留与删除

关闭处理页面后，扩展不保留已选择文件。用户下载的输出文件由浏览器保存到用户选择的位置。浏览器和扩展商店自身的安装、更新及遥测行为受其各自隐私政策约束。

权限和网络

PDF小匠 1.0 不申请扩展权限或网站访问权限。运行时代码和依赖均包含在扩展包中，断网时仍可使用全部文档处理功能。

第三方组件

扩展在本地使用 PDF.js、pdf-lib、fflate 和 docx-preview。这些组件随扩展执行，不会因此向组件维护者传输文件。

自愿支持

扩展内的“支持开发”入口仅显示随扩展包提供的微信支付收款码。用户自愿扫码后的支付由微信支付处理并受其政策约束；PDF小匠不读取、收集或保存支付账户及交易信息，Microsoft、Google 和浏览器扩展商店也不是收款方或赞助者。支持不会解锁任何功能。

联系与变更

隐私问题可通过项目 GitHub 仓库的 Issues 联系维护者。如果数据实践发生变化，本政策和商店披露会在新版本发布前同步更新。

Privacy Policy

Effective: September 17, 2026

Files explicitly selected by the user are processed only in the extension page's memory to create the requested output. PDF小匠 does not collect, upload, sell, share, retain, or analyze files, filenames, document contents, identity data, browsing activity, location, device identifiers, usage telemetry, payment accounts, or transaction information. It has no accounts, cookies, ads, backend, remotely hosted code, extension permissions, or host permissions. Closing the processing page discards selected inputs from extension memory.

The optional “Support Development” entry only displays a bundled WeChat Pay QR code; any voluntary payment is processed by WeChat Pay under its policies and unlocks no features. Microsoft, Google, and the browser extension stores are not the payee or sponsor. Browser and store installation, update, and telemetry behavior is governed by their respective policies.
